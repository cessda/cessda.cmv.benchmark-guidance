# Navigation Structure of CESSDA FAIR Benchmark Guidance

This is the record of how the various sections are structured,
and should be used by developers for reference, and updated when new pages are added.

It is not intended for publication.

The numbers in parenthesis refer to the nav_order value which is set in the header of each page.

The indentation is intended to indicate major sections, subsections and sub-subsections.

```none
(000) CESSDA FAIR Benchmark Guidance (index.md)
  (010) How to pass Persistent Identifier Schema Validation (pid.md)
  (020) How to pass Globally Unique Identifier Validation (guid.md)
  (030) How to pass Structured Metadata Validation (structured-metadata.md)
  (040) How to pass Grounded Metadata Validation (grounded-metadata.md)
  (050) How to pass Searchable Metadata Validation (searchable.md)
```
